# LexActivator C/C++ Example

Example demonstrating license activation with the LexActivator C/C++ licensing library.

## Running

Edit [Sample.cpp](Sample.cpp) and replace the placeholder `product_data`, `product_id`,
and `license_key` values with the ones from your Cryptlex dashboard.

On Linux/macOS, build with the provided [Makefile](Makefile):

```bash
make
```

On Windows, open [Sample.sln](Sample.sln) in Visual Studio and build.
