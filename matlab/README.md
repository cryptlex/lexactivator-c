# LexActivator MATLAB Example

Example demonstrating license activation with the LexActivator MATLAB licensing library.

## Running

Edit [Sample.m](Sample.m) and replace the placeholder `product_data`, `product_id`,
and `license_key` values with the ones from your Cryptlex dashboard, then run `Sample`
from the MATLAB console.
