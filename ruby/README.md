# LexActivator Ruby Example

Example demonstrating license activation with the LexActivator API binding for Ruby (licensing library).

## Running

Edit [sample.rb](sample.rb) and replace the placeholder `product_data`, `product_id`,
and `license_key` values with the ones from your Cryptlex dashboard, then run:

```bash
ruby sample.rb
```
