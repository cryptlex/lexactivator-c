# LexActivator Delphi Example

Example demonstrating license activation with the LexActivator Delphi licensing library.

## Running

This directory contains two samples:

- [Sample.dpr](Sample.dpr) — console sample
- [GUISample.dpr](GUISample.dpr) — VCL GUI sample

Open the desired `.dpr` in the Delphi IDE, edit the source and replace the placeholder
`product_data`, `product_id`, and `license_key` values with the ones from your Cryptlex
dashboard, then compile and run.
